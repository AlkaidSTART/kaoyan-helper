# P1 - 核心业务组件体系设计

## 1. 题库刷题模块设计 (`QuizView`)
- **排版容器**：`ConstrainedBox(maxWidth: 768)` 居中对齐，大留白。
- **状态流转**：
  - 选项未选：可点击。
  - 点击后锁定：正确项显示浅绿底 (`#EAF5F0`)、绿边框与勾选图标；若选错，该项显示浅红底 (`#FBECEB`)、红边框与叉号图标，触发 180ms 水平微颤（±4px）。
  - 解析区域：`AnimatedCrossFade` 展开（250ms），包含“AI 深度解析”与“下一题”。

## 2. 错题本模块设计 (`MistakesView`)
- **多维筛选栏**：
  - 学科 Chip：政治、英语、数学、专业课（对应 `SemanticColors` 学科底色与文字色）。
  - 状态 Chip：待消除 (红点)、已掌握 (绿点)。
- **错题卡片 (`MistakeCard`)**：
  - 顶部徽标：`[政 · 单选]`。
  - 状态：`StatusDot` 动态展示红/黄/绿。
  - 底部操作行：查看解析、立即重做。

## 3. 择校报录模块设计 (`SchoolsView`)
- **筛选区域**：院校搜索栏、985/211/双一流 FilterChip。
- **报录比数据行 (`SchoolRowItem`)**：
  - 报录比标签：>10 危险红，5-10 警告黄，<=5 达标绿（统一使用 `StatusDot` 与浅底深字）。
  - 历年趋势：点击展开卡片，展示 2022-2024 年分数线与报录趋势。
  - 目标星标：点击切换收藏高亮。

## 4. 记忆闪卡模块设计 (`FlashcardsView`)
- **3D 翻转卡片 (`FlipCard`)**：
  - `Transform` + `Matrix4` 景深 `0.0012`。
  - 翻转耗时 320ms，`Curves.easeOutCubic`。
  - 在翻转达到 $\pi/2$ 时切换正面（单词/音标）与反面（中文释义/真题考点）。
- **评级控制**：
  - 忘记 (1, 红点)、模糊 (2, 黄点)、牢记 (3, 绿点)。
  - 评级触发后切入下一张卡片，顶部 `LinearProgressIndicator` 平滑递增。
