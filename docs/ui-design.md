## 1. 设计哲学

### 1.1 核心原则

- **暖色简约**：温暖而不幼稚，简约而不简陋。目标是"让大学生觉得这个产品审美在线"。
- **抗疲劳优先**：考研生每天盯屏 6-10 小时，色彩饱和度克制、对比度舒适、大面积留白降低视觉负担。
- **沉浸无干扰**：答题、背诵等核心场景尽量减少视觉噪声，信息层次清晰。
- **触摸友好**：桌面+平板为主力设备，所有可交互元素最小触摸区域 44x44px，支持 touch 事件。

### 1.2 竞品参考与差异化

| 竞品 | 风格特征 | 登科的差异 |
|---|---|---|
| Anki | 功能强但 UI 粗糙、极客向 | 保留间隔复习科学性，大幅提升视觉体验 |
| 粉笔考研 | 偏活泼可爱、粉色系 | 更内敛克制，不幼稚化 |
| 考研帮 | 信息密集、门户感重 | 更聚焦单一任务场景，减少干扰 |
| Notion | 极简灰白、工具感 | 增加温度感和学习氛围，不是冷工具 |

## 2. 主题系统 (Theme System)

### 2.1 三套可切换主题

用户可在设置中切换，默认「暖阳」。通过 Tailwind CSS 的 CSS 变量机制实现，零运行时切换。

#### 主题一：「暖阳」(Warm Amber) — 默认

设计意图：日出金橙色调，温暖有活力，长时间使用不刺眼。

| 角色 | CSS 变量 | 色值 | Tailwind 近似 | 说明 |
|---|---|---|---|---|
| 品牌主色 | `--primary` | `#E07B39` | orange-500 偏暖 | 按钮、选中态、品牌焦点 |
| 品牌浅色 | `--primary-light` | `#FFF3E8` | — | 品牌色背景/hover 态 |
| 页面底色 | `--bg-base` | `#FFFBF5` | — | 全局底层背景，奶油暖白 |
| 卡片/容器 | `--bg-card` | `#FFFDF9` | — | 卡片、面板、弹窗 |
| 主文字 | `--text-primary` | `#3D2C1E` | stone-900 偏暖 | 标题、题干 |
| 次要文字 | `--text-secondary` | `#7C6B5D` | stone-600 偏暖 | 描述、标签 |
| 弱文字 | `--text-muted` | `#B0A395` | stone-400 偏暖 | 占位符、辅助说明 |
| 边框/分割 | `--border` | `#E8DDD2` | — | 暖灰边框 |
| 成功/正确 | `--success` | `#2E9E6E` | emerald-600 | 答对、打卡完成 |
| 警告/复习 | `--warning` | `#D4912A` | amber-600 | 错题标记、复习提醒 |
| 错误/危险 | `--danger` | `#D4453A` | red-600 偏暖 | 答错、删除 |

#### 主题二：「晚樱」(Soft Coral)

设计意图：柔桃粉色调，柔和文艺，适合喜欢温柔色系的用户。

| 角色 | CSS 变量 | 色值 | 说明 |
|---|---|---|---|
| 品牌主色 | `--primary` | `#E8806A` | 珊瑚橘粉 |
| 品牌浅色 | `--primary-light` | `#FFF0ED` | 极浅粉底 |
| 页面底色 | `--bg-base` | `#FFFAF9` | 微粉白 |
| 卡片/容器 | `--bg-card` | `#FFFCFB` | 纯净微粉 |
| 主文字 | `--text-primary` | `#3A2828` | 暖褐黑 |
| 次要文字 | `--text-secondary` | `#7D6565` | 灰褐 |
| 边框/分割 | `--border` | `#EADAD7` | 浅粉灰边框 |

成功/警告/错误色沿用「暖阳」同一套语义色，保持一致性。

#### 主题三：「素纸」(Clean White)

设计意图：纯白极简，接近 Notion/Linear 的工具感，最低视觉干扰。

| 角色 | CSS 变量 | 色值 | 说明 |
|---|---|---|---|
| 品牌主色 | `--primary` | `#5B7FD6` | 低饱和蓝灰 |
| 品牌浅色 | `--primary-light` | `#EFF3FB` | 极浅蓝 |
| 页面底色 | `--bg-base` | `#FAFAFA` | 纯白微灰 |
| 卡片/容器 | `--bg-card` | `#FFFFFF` | 纯白 |
| 主文字 | `--text-primary` | `#1A1A1A` | 近黑 |
| 次要文字 | `--text-secondary` | `#6B7280` | gray-500 |
| 边框/分割 | `--border` | `#E5E7EB` | gray-200 |

### 2.2 主题切换实现方案

```css
/* globals.css */
:root { /* 暖阳 - 默认 */
  --primary: #E07B39;
  --bg-base: #FFFBF5;
  /* ... */
}

[data-theme="coral"] {
  --primary: #E8806A;
  --bg-base: #FFFAF9;
  /* ... */
}

[data-theme="clean"] {
  --primary: #5B7FD6;
  --bg-base: #FAFAFA;
  /* ... */
}
```

Tailwind 通过 `theme.extend.colors` 映射 CSS 变量：`bg-base`, `text-primary`, `border-default` 等语义 class 自动跟随主题切换。

## 3. 字体与排版

### 3.1 字体栈

```css
--font-sans: "Inter", system-ui, -apple-system, "PingFang SC",
             "Microsoft YaHei", "Noto Sans SC", sans-serif;

--font-mono: "JetBrains Mono", "Fira Code", "SF Mono", monospace;
```

- Inter 作为英文主字体（Google Fonts 加载），中文回退系统字体。
- 代码块与数学公式用 mono 字体栈。

### 3.2 字号体系 (基于 Tailwind 默认 + 微调)

| 用途 | Class | 大小 | 行高 | 字重 |
|---|---|---|---|---|
| 页面大标题 | `text-2xl` | 24px | 32px | `font-bold` (700) |
| 模块标题 | `text-xl` | 20px | 28px | `font-semibold` (600) |
| 题干正文 | `text-base` | 16px | 26px | `font-normal` (400) |
| 选项文字 | `text-base` | 16px | 24px | `font-normal` (400) |
| 辅助说明 | `text-sm` | 14px | 20px | `font-normal` (400) |
| 标签/徽章 | `text-xs` | 12px | 16px | `font-medium` (500) |

题干正文行高特意加大到 26px（1.625 倍），长文本阅读更舒适。

### 3.3 数学公式渲染
- 引擎：KaTeX（比 MathJax 快 10x+）。
- 行内公式：`$...$`，块级公式：`$$...$$`。
- AI 回复中自动识别并渲染 LaTeX。

## 4. 间距与圆角规范

| Token | 数值 | 用途 |
|---|---|---|
| `--radius-sm` | 6px | 按钮、输入框、标签 |
| `--radius-md` | 10px | 卡片、面板 |
| `--radius-lg` | 16px | 弹窗、大面板 |
| `--radius-full` | 9999px | 头像、圆形按钮 |

间距遵循 Tailwind 4px 基数（`p-2` = 8px, `p-4` = 16px, `p-6` = 24px），不使用自定义间距值。

### 5.2 平板端布局 (768px ~ 1023px)

- Sidebar 默认折叠为图标模式 (`w-16`)，点击 hamburger 展开为 overlay。
- 主内容区撑满宽度。
- 触摸优化：所有按钮/选项增加 touch padding。

### 5.3 手机端布局 (< 768px)

- Sidebar 消失，转为底部导航栏 (Bottom Tab Bar, h-16)。
- 底部 Tab：看板 | 刷题 | 背诵 | 择校 | AI（最多 5 个）。
- Header 简化：仅 Logo + 倒计时 + 头像。
- **注意**：手机端不是 MVP 重点优化对象，保证基本可用即可。

### 6.2 答题页 (Quiz)

**设计原则**：最小干扰、聚焦题目本身。

**布局**：
- 居中卡片，`max-w-3xl` (768px)，两侧大面积留白。
- 题目卡片内部间距充裕（`p-8`）。

**交互流程**：

**触摸支持**：选项卡片可触摸点击，触摸区域覆盖整个卡片行。

### 6.6 AI 助教 (Chat)

**两种唤起方式，统一交互体验**：

- 右侧滑出，宽度 `480px`（平板端 `100vw` 全屏覆盖）。
- 不中断当前答题上下文。
- 抽屉顶部展示当前题目摘要。

#### B. 独立对话页 (`/chat`)
- 全屏对话界面，左侧科目选择面板 + 右侧聊天区。
- 预设科目快捷 Prompt 按钮。

### 6.7 管理后台 (`/admin`)

**设计原则**：功能优先、不需要品牌温度，采用「素纸」主题固定配色（灰白蓝）。

**布局**：独立的 admin Layout，左侧导航（题库管理/用户管理/数据看板/UGC 审核），右侧工作区。

- 数据看板：统计卡片 (DAU, 答题量, AI 调用次数, 成本估算) + 简单折线/柱状图。
- 题库管理：标准 CRUD 表格 + 筛选 + 批量导入（JSON/CSV 文件上传）。
- 用户管理：搜索 + 列表 + 封禁/解封操作。
- UGC 审核：待审核队列 + 预览题目内容 + 通过/驳回按钮。

## 7. 动效与过渡规范

| 场景 | 动效 | 时长 | 缓动 |
|---|---|---|---|
| 页面切换 | 无（Next.js 路由即时） | — | — |
| 侧边栏折叠/展开 | width 过渡 | 200ms | `ease-out` |
| 卡片翻转 | `rotateY(180deg)` | 400ms | `ease-in-out` |
| AI 抽屉滑入 | `translateX(100%) → 0` | 250ms | `ease-out` |
| 选项判定反馈 | 背景色渐变 | 200ms | `ease` |
| 按钮 hover/active | `scale(0.98)` + 颜色过渡 | 100ms | `ease` |
| Toast 通知 | 底部向上滑入 + 自动消失 | 入 200ms / 留 3s / 出 150ms | `ease` |

原则：**所有动效 <= 400ms**，不做无意义的延迟或弹性动画，尊重用户时间。支持 `prefers-reduced-motion` 媒体查询关闭动效。

## 8. 响应式断点

| 断点 | 范围 | 布局策略 | 触摸支持 |
|---|---|---|---|
| `xl` | >= 1280px | 完整三栏（Sidebar 展开 + 内容 + 可能的右侧面板） | 非必须 |
| `lg` | 1024px ~ 1279px | Sidebar 展开 + 内容 | 触摸支持 |
| `md` | 768px ~ 1023px | Sidebar 折叠为图标 + 内容撑满 | 触摸优先 |
| `sm` | < 768px | 底部导航 + 内容撑满 | 触摸优先 |

所有交互元素最小触摸目标 `44x44px` (WCAG 2.2 AAA)。
