# 响应式布局与适配规范 (Layout & Adaptive)

> 技术方案：Flutter `LayoutBuilder` / `MediaQuery.sizeOf` + 原生自适应 Shell

---

## 1. 响应式断点标准

| 端形态 | 屏幕宽度 (w) | 导航模式 | 布局结构 | 交互重点 |
|---|---|---|---|---|
| **桌面端 (Desktop)** | `>= 1024px` | `NavigationRail` (72px折叠 / 240px展开) | 三栏（侧栏 + 内容主区 + 右侧AI抽屉） | 键鼠友好、悬浮状态、多栏并发 |
| **平板端 (Tablet)** | `768px ~ 1023px` | 折叠 `NavigationRail` (72px) / Modal Drawer | 双栏或单栏（AI 转为 `endDrawer`） | 触控优先 (48x48dp 热区) |
| **移动端 (Mobile)** | `< 768px` | 底部 `NavigationBar` (5 个 Tab) | 纯单列纵向流，页面满屏呈现 | 纯单手触控，次要信息收纳 |

## 3. 全局快捷键规范 (Desktop Keyboard Shortcuts)

通过顶层 `Shortcuts` + `Actions` 绑定：

| 快捷键 | 动作 | 触发范围 |
|---|---|---|
| `Cmd/Ctrl + B` | 展开 / 折叠导航侧边栏 | 全局 |
| `Cmd/Ctrl + J` | 展开 / 收起 AI 助教面板 | 做题页 / 错题页 |
| `Cmd/Ctrl + K` | 唤起全局搜索 / 择校搜索 | 全局 |
| `Esc` | 关闭弹窗 / 收起右侧 AI 面板 | 全局 |
| `A / B / C / D` | 选项快速单选 | 刷题页 |
| `Enter` / `→` | 确认提交 / 下一题 | 刷题页 |
| `1 / 2 / 3` | 忘记 / 模糊 / 牢记 | 闪卡背诵页 |

---

## 4. 桌面窗口规范 (macOS / Windows)

- 最小尺寸限制：`900 x 600`（避免布局挤压破损）。
- 使用 `window_manager` 进行生命周期托管。
- macOS：支持隐藏原生标题栏，自绘融入 AppBar。
