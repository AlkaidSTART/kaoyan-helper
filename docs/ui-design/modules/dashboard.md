## 2. 动效与微交互

- **数据卡片进场**：数字通过 `TweenAnimationBuilder<int>` 滚入（350ms，`Curves.easeOutCubic`）。
- **进度条加载**：`LinearProgressIndicator` 结合 `TweenAnimationBuilder<double>` 平滑涨满。
- **图表渲染**：`fl_chart` 的 LineChart 启用初始描线动画（`swapAnimationDuration: Duration(milliseconds: 400)`）。

---

## 3. 配色规则

- 倒计时数字：`primary` 橙色，加粗 28sp。
- 连续打卡火苗：`#E07B39` 主色。
- 目标院校报录标签：根据比例动态匹配 `SemanticColors`（`>10` 危险红，`5-10` 警告黄，`<=5` 达标绿）。
- 卡片底色：`surfaceContainerLowest` 上承载 `surface` 纯白卡片，边框用 `outlineVariant`。
