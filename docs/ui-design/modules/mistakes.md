# 模块设计：错题归纳 (Mistakes)

> 路由：`/mistakes` | 角色：错题收录、靶向攻坚与消除

---

## 1. 界面与布局

```
+─────────────────────────────────────────────────────────────+
| [多维筛选栏] Wrap of FilterChip                              |
| 科目: [全部] [政治] [英语] [数学] [专业课] (各学科专属色底)  |
| 题型: [全部] [单选] [多选] [分析/简答]                       |
| 状态: [ChoiceChip: 待消除 (23) (含 StatusDot: danger)] [ChoiceChip: 已掌握 (85) (含 StatusDot: success)]|
| 排序: [Dropdown: 错误频次最高 ▾]                              |
+─────────────────────────────────────────────────────────────+
| [攻坚浮动栏]                                                 |
| [ElevatedButton.icon: (Icon: play_arrow_rounded, '开始错题攻坚 (随机 10 题)')]|
+─────────────────────────────────────────────────────────────+
| [错题列表] ListView.builder                                  |
| ┌─────────────────────────────────────────────────────────┐ |
| │ Card:                                                   │ |
| │ [政·单] 矛盾的普遍性与特殊性辩证关系原理...                │ |
| │ 最近做错: 2小时前 | 错误次数: 3次                        │ |
| │ 状态徽标: [StatusDot: danger] 待消除 (需连续做对 2 次消除) │ |
| │                                                         │ |
| │ 操作: [TextButton: 立即重做] [TextButton: 查看官方/AI解析] │ |
| └─────────────────────────────────────────────────────────┘ |
+─────────────────────────────────────────────────────────────+
```

---

## 2. 状态流转与配色

| 状态 | 判定规则 | Badge 背景 | 文字色 |
|---|---|---|---|
| **待消除** | 最近答错，或连续正确次数 `< 2` | `SemanticColors.danger` 浅底 (`#FBECEB`) | `#93231C` |
| **已掌握** | 攻坚练习中连续做对 `>= 2` 次 | `SemanticColors.success` 浅底 (`#EAF5F0`) | `#175B3D` |

---

## 3. 攻坚动效
- 点击"标记为已掌握"或重做做对消除错题时，列表项高度使用 `SizeTransition` 平滑折叠收起（250ms），随后从待消除列表中移除。
