## 2. 错题卡片组件规范 (MistakeCard)

### 2.1 UI 结构与尺寸
- **卡片容器**：全宽，圆角 `14 dp`，内边距 `16 dp`，外边距上下 `6 dp`。
- **顶部 Header**：
  - 学科+题型徽标：`[政 · 单选]`（学科专属低饱和背景 + 深色文字，高 `24 dp`，圆角 `6 dp`）。
  - 右侧状态点与消除条件：`StatusDot`（红 6px）+ `需连对 2 次消除`（`12sp` 弱提示）。
- **中心题干与错误摘要**：
  - 题干精简（两行截断 `TextOverflow.ellipsis`，行高 `20sp`，字号 `15sp`）。
  - 下方错误详情行：`最近答错: 2小时前` · `错题频次: 3次`（带有醒目的暖橙/弱红强调数值）。
- **底部操作行 (Row)**：
  - 左侧：`IconButton(Icons.delete_outline)`（移出收纳）。
  - 右侧按钮组：
    - `TextButton.icon(Icons.menu_book_outlined, '查看解析')`。
    - `FilledButton.tonalIcon(Icons.replay_rounded, '立即重做')`（高度 `36 dp`）。

### 2.2 状态流转与配色 (暖阳主题)

| 状态 | 卡片背景 | 卡片边框 | 状态徽标 | 错误频次徽标 | 重做按钮 |
|---|---|---|---|---|---|
| **待消除 (需攻坚)** | `surface` (`#FFFDF9`) | `outlineVariant` (`#E8DDD2`) | 红点 + `#FBECEB` 浅红底 | `#D4453A` 弱红加粗 | `primaryContainer` 底 + `onPrimaryContainer` 字 |
| **临界掌握 (已连对 1 次)** | `surface` (`#FFFDF9`) | `warning` 30% 边框 | 黄点 + `#FEF7E6` 浅黄底 | `#D99014` 橙黄提示：“再对1次即消除” | 暖橙高亮按钮 |
| **已掌握 (已消除)** | `surfaceContainerLow` (`#FFF8F0`) | 淡化无边框 | 绿点 + `#EAF5F0` 浅绿底 | 变灰绿“已掌握” | 幽灵灰按钮：“巩固” |

## 3. 攻坚流转与消除动效

1. **悬浮态 (Hover)**：
   - 边框颜色平滑过渡为 `primary` 35%，阴影轻微上浮 `elevation: 1 -> 3`（`150ms`, `Curves.easeOut`）。
2. **重做做对 · 阶段 1：连对 1 次升级**：
   - 状态徽标原位缩放微弹 `scale: 1.0 -> 1.15 -> 1.0`（`180ms`），红点过渡为黄点。
3. **重做做对 · 阶段 2：完全消除达成（从待消除列表移除）**：
   - **步骤 1**：卡片右侧滑出绿色勾号遮罩（`SlideTransition`，`180ms`），同时整卡背景由白转 `successContainer` 淡绿。
   - **步骤 2**：停留 `150ms` 确认感。
   - **步骤 3**：整行使用 `SizeTransition`（配合 `FadeTransition`）垂直高度从 `1.0 -> 0.0` 塌陷折叠（`240ms`，`Curves.easeOutCubic`），下方列表顺滑顶上，无突兀闪烁。
4. **批量攻坚悬浮条 (Floating Action Bar)**：
   - 随页面滚动动态吸附在底部，向上滑动隐藏、停止时淡入呈现。
