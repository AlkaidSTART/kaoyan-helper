# 模块设计：休息放松与专注管理 (Rest & Focus)

> 路由：`/rest` | 角色：缓解高频盯屏疲劳、心率平复与全局番茄钟控制

---

## 1. 悬浮球番茄钟 (FloatingPomodoroBubble)

### 1.1 UI 形态与状态
- **收起态（小球）**：
  - 尺寸：`48×48 dp`，默认靠右吸附。
  - 外圈：2.5px 环形进度条 (`CircularProgressIndicator`)。
  - 中心：剩余时间（如 `24m`）或暂停图标。
- **展开态（微控制面板）**：
  - 尺寸：`260×180 dp` 悬浮浮层 (`surfaceContainerHighest`)，圆角 `16 dp`。
  - 内容：模式选择 Chip（专注 25m / 深度 50m / 短休 5m）、大字倒计时、操作键组（暂停/重置/前往休息）。
- **手势交互**：
  - 自由拖拽：`Draggable` 跟随手指或鼠标光标。
  - 边缘吸附：松手后 `180ms` 内平滑吸附至屏幕最近左/右边缘（边距 `12 dp`）。
  - 关闭机制：面板提供右上角 `Icons.close`；拖动至屏幕底部边缘出现的删除区亦可关闭。关闭状态持久化于本地轻量配置。
  - 重新唤起：在 `/rest` 页面顶部栏显式展示“显示番茄钟”操作 Chip。

### 1.2 配色与动效
- **专注阶段**：外圈主色 `primary` (`#E07B39`)，浅底 `primaryContainer` (`#FFF3E8`)。
- **休息阶段**：外圈浅绿 `success` (`#2E9E6E`)，浅底 `successContainer` (`#EAF5F0`)。
- **呼吸动效**：计时中外圈每 3 秒发生轻微光晕放缩 (`scale: 1.0 -> 1.05 -> 1.0`, 不透明度 `0.2 -> 0.0`)。
- **展开收起**：`ScaleTransition` + `FadeTransition` (`200ms`, `Curves.easeOutCubic`)。

## 2. 休息页结构 (/rest)

全屏沉浸容器（`surfaceContainerLowest`），隐藏主侧边导航栏，支持按 `Esc` 或左上角返回按钮快速退出。

顶部工具栏中心使用 `SegmentedButton` 提供三种解压模式：
1. **深呼吸 (Breathing)**
2. **木鱼 (Muyu)**
3. **舒尔特方格 (Schulte Grid)**

---

## 3. 子功能组件规范

### 3.1 考研解压木鱼 (MuyuReliefWidget)
- **主体 UI**：居中 `180×180 dp` 矢量木鱼，下方配置半透明阴影。
- **顶部数据**：小字“今日心流”，大字计数（`28sp Bold`，`TweenAnimationBuilder` 平滑滚量）。
- **敲击反馈**：
  - 木鱼下沉回弹：`scale: 1.0 -> 0.92 -> 1.0`（耗时 `90ms`，`Curves.easeOutQuad`）。
  - 飘字浮升：随机文案（如“上岸+1”、“心流+1”、“一志愿拟录取+1”），向上漂浮 `dy: 0 -> -60 dp`，透明度由 `1.0 -> 0.0`，时长 `650ms`。
  - 音频与振动：轻量木鱼音效文件 + `HapticFeedback.lightImpact()`。
  - 桌面端支持按 `Space` 键敲击。

### 3.2 舒尔特方格 (SchulteGridWidget)
- **网格规范**：
  - 尺寸：`5×5` 乱序矩阵，桌面端最大限定 `360×360 dp`，移动端两侧留 `32 dp`。
  - 单格：`InkWell`，圆角 `8 dp`，间隙 `6 dp`。
- **顶部信息**：当前目标数字提示（如：`目标: 14`）、实时秒表（`00:18.4`）、重置键。
- **微交互与配色**：
  - 待选态：底色 `surface`，边框 `outlineVariant`，文字主色。
  - 正确点选：格子微缩放 (`scale: 0.95 -> 1.0`, `100ms`)，底色瞬间过渡至 `successContainer`，数字淡化为半透明绿灰，降低视觉负荷。
  - 错误点选：单格横向抖动（振幅 `±3px`，`120ms`），底色变 `dangerContainer`。
  - 全部完成：淡入结果弹卡，呈现耗时及专属解压评级。
