## 2. 报录比数据采集与双层兜底架构

1. **层 1：官方与高校爬虫（自动抓取）**
   - 定时爬取研招网、高校研究生院官网拟录取公示名单与调剂公告，自动入库公共数据集。
2. **层 2：用户端文档解析（OCR + LLM 双层兜底）**
   - 针对冷门院系或未及时收录的拟录取名单，用户直接上传本地公示文档（PDF / 截图 / XLSX）。
   - **OCR 引擎**：负责版面分析、表格提取与文字识别。
   - **大模型 (LLM)**：语义结构化提取专业代码、年份、初复试线、录取人数等字段，输出标准 Schema。

## 3. 上传与解析组件规范 (SchoolDataUploadDialog)

### 3.1 UI 结构与交互流程
- **形态**：桌面端居中弹窗（宽 `560 dp`），移动端为底部浮层（`showModalBottomSheet`）。
- **待上传区**：
  - `DottedBorder` 虚线框（`outlineVariant`，圆角 `12 dp`，高度 `160 dp`）。
  - 图标：`Icons.cloud_upload_outlined`（36 dp，`primary`）。
  - 提示：“拖入或点击上传研招网公示名单 (PDF / XLSX / JPG / PNG)”。
- **多阶段进度流水线**：
  - 阶段 1：OCR 提取版面与表格文字。
  - 阶段 2：LLM 结构化抽取报录与分数字段。
  - 阶段 3：规则引擎数据校验与置信度打标。
- **校验与校对预览表**：
  - 高置信度字段显示绿点（`success`）。
  - 存疑字段（模糊或未精准匹配）显示黄点（`warning`），支持用户点击原位编辑修正。
  - 操作栏：`[放弃]` / `[确认入库并更新趋势图]`。

### 3.2 配色与动效
- **拖拽激活**：背景过渡至 `primaryContainer`，虚线变为 2px 主色，带 `scale: 1.0 -> 1.02` 微弹跳（`120ms`）。
- **阶段流转**：阶段图标由加载中平滑切换为绿勾（`AnimatedSwitcher`，`150ms`）。
- **入库更新**：确认入库后弹窗淡出（`150ms`），对应院校的趋势折线图以 `ScaleTransition`（0 -> 1.0）动态加入新数据点。

## 4. 历年趋势图表规范 (SchoolTrendChart)

### 4.1 图表参数与排版
- **依赖库**：`fl_chart`。
- **高度**：`220 dp`，内边距 `上下 16 dp，左右 24 dp`。
- **双 Y 轴设计**：
  - 左 Y 轴：分数线（如 340 ~ 400 分）。
  - 右 Y 轴：报考与录取人数（如 0 ~ 500 人）。
  - X 轴：年份（近 3 ~ 5 年）。
- **顶部图例**：3 个药丸 Chip，支持点击单选高亮或隐藏单一指标。

### 4.2 系列配色与报录比色值 (暖阳主题)

| 数据系列 | 折线颜色 | 渐变底色 | 数据点样式 |
|---|---|---|---|
| **复试线 (Score)** | `primary` (`#E07B39`, 2.5px 粗线) | 无渐变（保持清爽不重叠） | 6px 实心圆点，带 2px 白边 |
| **报名人数 (Applicants)** | 青蓝 (`#32939B`, 1.5px 虚线) | 极浅青蓝渐变（透明度 0.15 -> 0.0） | 4px 小方块/圆点 |
| **录取人数 (Admitted)** | 灰靛蓝 (`#5671B5`, 2.0px 实线) | 极浅灰蓝渐变（透明度 0.20 -> 0.0） | 5px 实心圆点 |

- **报录比烈度标签**：
  - `> 10:1`（极度内卷）：`dangerContainer` 浅红底 (`#FDF0ED`) + `danger` 深红字 (`#93231C`)。
  - `5:1 ~ 10:1`（常规竞争）：`warningContainer` 浅黄底 (`#FEF7E6`) + `warning` 棕黄字 (`#874D00`)。
  - `< 5:1`（相对温和）：`successContainer` 浅绿底 (`#EAF5F0`) + `success` 墨绿字 (`#175B3D`)。

### 4.3 动效规范
- **绘制展开**：折线沿 X 轴自左向右绘制（`swapAnimationDuration: 300ms`, `Curves.easeOutCubic`）。
- **准星吸附 (Tooltip)**：Hover 或长按年份，1px 浅灰竖向准线瞬时吸附，显示包含当年四项指标的圆角浮层气泡。
- **设为目标星标**：点击 `AnimatedScale`（1.0 -> 1.3 -> 1.0，`180ms`），由空心线框变为暖金实心高亮。
