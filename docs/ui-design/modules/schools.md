## 2. 报录比颜色语义与图表配色

1. **报录比色值**：
   - `> 10.0:1`：`SemanticColors.danger`（竞争白热化）
   - `5.0:1 ~ 10.0:1`：`SemanticColors.warning`（适中）
   - `<= 5.0:1`：`SemanticColors.success`（相对宽松）
2. **图表配色 (fl_chart)**：
   - 复试线指标：主品牌橙色（`#E07B39`）
   - 报名人数指标：青蓝序列色（`#32939B`）
   - 录取人数指标：灰蓝序列色（`#5671B5`）
3. **收藏目标院校动效**：
   - 点击星标按钮触发 `AnimatedScale` 放大（1.0 -> 1.25 -> 1.0，时长 200ms），实心黄色高亮，顶部 AppBar 目标院校 Chip 即刻同步更新。
