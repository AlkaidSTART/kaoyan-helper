# 模块设计：AI 助教 (AI Chat)

> 形态：桌面侧边抽屉面板 (400px) & 独立页面 (`/chat`)

---

## 1. 界面与交互模式

### 1.1 侧边抽屉模式（做题/错题关联场景）
- **触发**：点击题目下方 `[Icon: auto_awesome, 'AI 深度解析']` 或按快捷键 `Cmd/Ctrl + J`。
- **桌面端**：右侧抽屉滑入，固定宽度 `400px`，时长 `250ms` (`Curves.easeOut`)。
- **上下文继承**：面板顶部固定卡片展示当前题目题干与用户所选答案，保持问答上下文一致。

### 1.2 独立页面模式 (`/chat`)
- 全屏对话，内容居中限制在 `ConstrainedBox(maxWidth: 768)`。

## 2. 动效与流式渲染

- **流式追加**：后端 SSE / WebSocket 逐 token 推送，`StreamBuilder` 动态追加内容。
- **额度警示**：每日调用额度剩余 `< 5 次` 时，右上角 Badge 颜色自动切至 `SemanticColors.warning` 黄色。
- **展开与收起**：`AnimatedContainer` 控制右侧宽度 `0 <-> 400px`，曲线 `Curves.easeOut`。
