# 模块设计：AI 助教 (AI Chat)

> 形态：桌面侧边抽屉面板 (400px) & 独立页面 (`/chat`)

---

## 1. 界面与交互模式

### 1.1 侧边抽屉模式（做题/错题关联场景）
- **触发**：点击题目下方 `[Icon: auto_awesome, 'AI 深度解析']` 或按快捷键 `Cmd/Ctrl + J`。
- **桌面端**：右侧抽屉滑入，固定宽度 `400px`，时长 `240ms` (`Curves.easeOutCubic`)。
- **上下文继承**：面板顶部固定卡片展示当前题目题干、用户错选选项及官方答案，支持点击折叠收起。

### 1.2 独立页面模式 (`/chat`)
- 全屏对话，内容居中限制在 `ConstrainedBox(maxWidth: 768)`。

## 2. 消息气泡规范 (AiMessageBubble)

### 2.1 AI 助教气泡（居左，卡片式）
- **容器结构**：背景 `surface` (`#FFFDF9`)，圆角 `16 dp`（左上角微圆角 `4 dp` 形成气泡朝向），全周带 `0.5px` 极细边界线 (`outlineVariant`)。
- **视觉锚点**：左侧边缘嵌 `3px` 品牌主色竖条 (`primary`)，突显学术权威感与沉浸感。
- **内容渲染**：支持 Markdown 结构化标题、加粗、有序列表与 `flutter_math_fork` 行内/块级 LaTeX 公式混排。
- **工具行**：底部淡灰色复制全文、重新生成及点赞/点踩反馈按钮组。

### 2.2 用户提问气泡（居右）
- **容器结构**：背景 `primary` (`#E07B39`)，圆角 `16 dp`（右上角 `4 dp` 导向），无多余线框。
- **文字样式**：`onPrimary` (`#FFFFFF`)，字号 `15sp`，行高 `22sp`。

## 3. 明朗交互输入底栏 (AiChatInputBar)

强调坚挺明朗的线条边界与高触感交互反馈，彻底告别平淡灰框。

### 3.1 尺寸与排版
- **高度范围**：最小基线 `52 dp`，随多行文本输入平滑自适应展开，上限 `130 dp`（溢出内部滚动）。
- **外轮廓**：圆角 `16 dp`，兼顾圆润手感与严谨工具质感。
- **三段式排版**：
  - 前置区：`IconButton(Icons.image_outlined)` 错题截图/附件上传，尺寸 `20 dp`。
  - 文本区：`TextField(maxLines: 5, minLines: 1)`，无下划线，字号 `15sp`。
  - 尾置区：`36×36 dp` 动态升格操作按键（发送 / 停止生成）。

### 3.2 边框线条与色彩流转状态

| 状态 | 容器背景 | 外边框线条 (Border) | 辉光/投影 | 发送按键形态 |
|---|---|---|---|---|
| **闲置 (Idle)** | `surface` (`#FFFDF9`) | `1.5px` 实线 `outlineVariant` (`#DFD5CA`)，边界棱角分明 | 零投影 | 浅灰线框，禁用态 |
| **鼠标悬停 (Hover)** | `surface` | `1.5px` 实线过渡至 `primary` 50% 纯度 (`#EF9E6E`) | 极浅微光 `0 2px 8px rgba(224,123,57,0.06)` | 悬浮提示小亮 |
| **聚焦 (Focused · 空)** | `surface` | **`2.0px` 坚挺高亮实线** (`#E07B39`) | **`3px` 主色半透明辉光** (`rgba(224,123,57,0.15)`) | 灰色线框等待输入 |
| **输入激活 (Active)** | `surface` | **`2.0px` 坚挺高亮实线** (`#E07B39`) | 辉光增强，伴随按键跳跃 | **升格为主色实心块** (`#E07B39` 底 + 白箭头) |
| **流式响应中 (Streaming)** | `surfaceContainerLow` | `1.5px` 青蓝线 (`#32939B`) | 线条呈现微弱呼吸流动感 | 变为微型方块“停止生成”按钮 |

### 3.3 交互微动效
1. **聚焦涟漪扩散 (Focus Pulse)**：
   - 聚焦瞬间：边框由 `1.5px` 瞬时切换至 `2.0px`，外层 `BoxShadow` 辉光在 `150ms` 内自内向外扩散 `0 -> 4px` (`Curves.easeOutCubic`)。
2. **发送键升格弹性 (Button Elevate)**：
   - 字数从 `0 -> 1` 时：发送按钮触发 `ScaleTransition`（`0.85 -> 1.05 -> 1.0`，`180ms`），瞬间填充为主色高亮。
3. **物理下凹与回车发送**：
   - 支持 `Enter` 快捷发送，`Shift + Enter` 换行。
   - 发送瞬间按键微凹 `scale: 0.92`（`70ms`），随后平滑回缩至 `52 dp` 单行高。
4. **流式追加与智能视口保护**：
   - 消息追加伴随 `▌` 呼吸闪烁光标（周期 `800ms`）。
   - 用户若主动向上滚动翻阅历史记录，智能锁定视口，防止流式文本强制拉扯画面。
