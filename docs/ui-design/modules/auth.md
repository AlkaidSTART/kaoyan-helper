## 2. 响应式布局与防遮挡避让

原图左上角嵌有手写体“考研 让你遇见更好的自己”，右上角嵌有晨光与“考研 上岸”旗标，中部桌前有手写“考研计划”笔记本与“向上生长”保温杯。

### 2.1 桌面端 / 平板（宽屏沉浸 + 右侧悬浮毛玻璃）
- **背景层**：
  - 全屏铺展 `assets/logo.png`，`BoxFit.cover`，锚定中心偏左，完整露出左侧题干书堆与右侧窗外晨曦。
- **悬浮认证卡片位姿 (Avoidance Layout)**：
  - 定位于屏幕**右侧偏中**（右间距 `80 dp`，上下居中，避让右上角旗标）。
  - 宽度固定 `400 dp`，内边距 `32 dp`，圆角 `24 dp`。
- **材质规范（晨曦透光毛玻璃）**：
  - 滤镜：`BackdropFilter(filter: ImageFilter.blur(sigmaX: 16, sigmaY: 16))`。
  - 背景色：`Color(0xCCFFFDF9)`（80% 不透明度暖白）。
  - 轮廓光：`1.5px` 半透明白金渐变线条（`Colors.white.withOpacity(0.65)`），使窗外穿透的自然阳光在卡片边缘形成剔透光边。
  - 阴影：`BoxShadow(color: Color(0x1F2C2623), blurRadius: 24, offset: Offset(0, 12))`。

### 2.2 移动端（垂直层次分层）
- **顶部视效 Banner（高度 220 dp）**：
  - 截取原图核心视觉（真题书、笔记本与晨光），底部叠加平滑渐变遮罩（`LinearGradient: transparent -> surface`）。
- **下半部认证卡片**：
  - 纯净暖米底向上平滑承接，软键盘弹起时不挤压背景画面。

## 3. 核心认证组件规范

### 3.1 标题与情感共鸣
- **主标题**：“开启今日研途”（`22sp Bold`，深墨蓝 `#204374`）。
- **副标题**：“桌前书本已备齐，向上生长正当时”（`13sp Regular`，暖灰褐 `#6E6259`，呼应图中保温杯标语）。

### 3.2 明朗线条输入框 (AuthInputField)
- **材质**：纯白微透底 `Colors.white.withOpacity(0.7)`。
- **边框**：
  - 默认态：`1.5px` 实线 `outlineVariant` (`#DFD5CA`)。
  - 聚焦态：升格为 **`2.0px` 晨曦高亮金线 (`#E67E22`)**，并向外辐射 `3px` 柔光（`rgba(230,126,34,0.18)`），边界利落清爽。
- **操作集成**：
  - 验证码内嵌倒计时（“获取验证码” -> “重新发送 (59s)”）。
  - 密码框集成一键显隐小眼睛图标。

### 3.3 晨曦金主登录按钮 (SunriseSubmitButton)
- **视觉**：`LinearGradient(colors: [#E67E22, #F39C12])` 晨曦双色渐变，高度 `48 dp`，圆角 `14 dp`。
- **文案**：“进入自习室 / 开启专注”（白色粗体 `16sp`）。
- **按压微反馈**：`AnimatedScale`（`1.0 -> 0.98`，`90ms`）。

### 3.4 第三方快捷登录组 (OAuth Row)
三枚磨砂白底药丸图标平铺（尺寸 `44×44 dp`，圆角 `12 dp`）：
1. **Google**：官方原版色彩 G 标。
2. **GitHub**：低饱和深灰 Octocat 图标。
3. **微信**：原生微信绿图标。

## 4. 动效与微交互

1. **进场晨曦光晕扫过 (Shimmer Sweep)**：
   - 页面初始加载完成，右侧晨光穿透毛玻璃，一道白金微光（`Shimmer`）在卡片边框流转一圈（`600ms`，`Curves.easeOut`），激活生机。
2. **输入即动力微动效**：
   - 输入框首次录入字符时，主登录按钮表面泛起极弱光斑呼吸，暗示“行动已就位”。
3. **错误抖动与未勾选协议提示**：
   - 验证码/密码错误：卡片横向颤动 `±4px`（`180ms`），线条闪红。
   - 未勾选协议：底部协议栏呼吸缩放 `1.0 -> 1.04 -> 1.0`（`140ms`）。
4. **登录成功无缝转场**：
   - 点击登录通过，卡片淡出，全景自习室画面平滑通过 `FadeThroughTransition`（`250ms`）延展过渡至 `/dashboard`。
