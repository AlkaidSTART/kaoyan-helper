### 1.1 桌面端 / 平板（宽屏左右分栏）
- **左侧：考研励志高能展区 (Flex 5)**：
  - 底色：`surfaceContainerLow` 暖米色，大面积开阔留白。

- **右侧：核心登录卡片区 (Flex 4)**：
  - 居中限制宽 `420 dp`，圆角 `20 dp`，内边距 `32 dp`。
  - 承载：Logo、双模式切换、输入框、第三方登录（Google / GitHub / 微信）。

## 2. 励志组件规范

### 2.1 全国研考倒计时看板 (TargetCountdownTile)
- **大字号**：`36sp Bold Monospace`，防抖动。
- **配色**：暖阳晨曦金色 (`#E07B39` / `#D48806`)，外层带极弱高斯模糊金色光晕。
- **动效**：进入页面时，天数由 `0` 平滑滚动至目标天数 (`TweenAnimationBuilder<int>`, `400ms`, `Curves.easeOutCubic`)。

### 2.2 实时共读战报徽标 (CoStudyLiveBadge)
- **形态**：胶囊 Chip，底色 `surface`，四周带浅灰细边。
- **状态指示**：左侧 `StatusDot` 呈现绿色 1.5 秒循环柔和呼吸动效（透明度 `0.4 <-> 1.0`）。
- **文案**：“此时此刻，**142,580** 位考研战友正在并肩自习”，数字加粗。

### 2.3 研途金句轮播 (DailyQuoteCarousel)
- **内容池**：励志诗词、备考心理疏导、考研上岸箴言。
- **切换动效**：每 6 秒使用 `AnimatedSwitcher` + `FadeThroughTransition` 平滑淡入切换（`300ms`）。

## 3. 认证组件与第三方登录规范

### 3.1 手机验证码与密码输入框 (AuthInputField)
- **线条质感**：
  - 默认态：`1.5px` 实线 `outlineVariant` (`#DFD5CA`)。
  - 聚焦态：升格为 **`2.0px` 坚挺实线 `primary` (`#E07B39`)**，并向外辐射 `3px` 柔光（`rgba(224,123,57,0.15)`）。
- **验证码倒计时按键**：
  - 激活态：`TextButton` 主色文字“获取验证码”。
  - 倒计时态：背景切至 `surfaceContainerHigh`，灰字“重新发送 (59s)”，禁用重复触控。
- **密码显隐键**：`IconButton(Icons.visibility_off_outlined)` 一键明文切换。

### 3.2 第三方登录按钮组 (OAuth Buttons)
集成 Supabase Auth 第三方登录协议：

1. **Google 登录 (`GoogleAuthButton`)**：
   - 样式：`surface` 底色 + `1.5px outlineVariant` 边框，图标为 Google 官方多色 G 标。
   - 文案：“通过 Google 账号登录”，居中黑字 `onSurface`。
2. **GitHub 登录 (`GithubAuthButton`)**：
   - 样式：深碳灰/低饱和黑灰质感，官方 Octocat 线性图标。
   - 文案：“通过 GitHub 账号登录”。
3. **微信扫码/授权登录 (`WeChatAuthButton`)**：
   - 微信品牌绿线性图标。

- **按压动效**：所有 OAuth 按钮点击触发 `AnimatedScale`（`1.0 -> 0.98`，`100ms`），回弹手感坚挺。

## 4. 校验与跳转微动效

1. **输入错误横向微颤 (Shake Animation)**：
   - 验证码错误或密码不匹配时，卡片或对应输入框触发振幅 `±4px` 的横向颤动（`180ms`），边框瞬时变红（`danger`）。
2. **未勾选协议弹跳提醒**：
   - 用户未勾选协议点击登录时，协议文字整行触发 `scale: 1.0 -> 1.04 -> 1.0`（`150ms`）呼吸弹跳，复选框边缘短暂泛红。
3. **点亮上岸 · 登录成功转场**：
   - 验证通过后，登录按钮浮现 `Icons.check_rounded` 对勾（`120ms`）。
   - 整页通过 `FadeThroughTransition`（`250ms`）丝滑转场至 `/dashboard`。
