## 2. 动效与手势规范 (极致丝滑标准)

### 2.1 3D 翻转动效 (物理级渲染)
- **触发**：点击卡片或按 `Space`。
- **参数**：
  - 时长：`320ms`（紧凑轻盈，杜绝拖沓）
  - 曲线：`Cubic(0.2, 0.0, 0.0, 1.0)`（iOS 原生物理缓动曲线）
  - 景深透视：`0.0012`（最贴合实体卡片厚度感）
- **性能与接缝处理**：
  - 正反双面包裹独立 `RepaintBoundary`，仅驱动矩阵，零排版重绘。
  - 在 `angle = π/2` 瞬间切换正反面子树，背面预设 `rotateY(π)`，彻底消除镜像反字伪影。

### 2.2 双层卡堆层叠感 (Stacked Card Flow)
- **静态层叠**：
  - 顶层操作卡：`scale: 1.0`，`offset: (0, 0)`，`opacity: 1.0`。
  - 底层预备卡：`scale: 0.94`，`offset: (0, 12dp)`，`opacity: 0.7`。
- **切卡无感交替**：
  - 顶卡滑出的同时（`220ms`），底卡在 `220ms` 内同步 `scale: 0.94 -> 1.0`、浮升至 `(0, 0)`、透明度达 `1.0`。
  - 全过程零黑屏、零空白帧，切卡如实体纸牌交替。

### 2.3 手势拖拽与阻尼弹簧 (Gesture Drag & Spring)
- **水平位移与倾角联动**：手势拖拽时伴随旋转 `rotationZ = (dx / screenWidth) * 0.15`（最大约 8 度自然倾角）。
- **弹性回弹**：未达触发阈值（水平位移 < 80dp）松手时，由 `SpringSimulation`（阻尼比 `0.8`）驱动弹簧平滑归位，严禁急停顿挫。
- **评级反冲飞出**：
  - 牢记 (1)：向右滑出带惯性飞离屏幕。
  - 忘记 (3)：向左滑出带惯性飞离屏幕。
  - 模糊 (2)：轻微下沉 `SlideTransition(dy: 0.4)` 并快速淡出。

## 3. 桌面端快捷键

| 按键 | 动作 |
|---|---|
| `Space` | 正面/背面 3D 翻转 |
| `1` | 标记：忘记 |
| `2` | 标记：模糊 |
| `3` | 标记：牢记 |
| `← / →` | 切换上/下一张（浏览模式） |
