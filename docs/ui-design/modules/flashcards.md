## 2. 动效与手势规范

### 2.1 3D 翻转动效
- **触发**：点击卡片或按 `Space`。
- **参数**：
  - 时长：`400ms`
  - 曲线：`Curves.easeInOut`
  - 矩阵：`Matrix4.identity()..setEntry(3, 2, 0.001)..rotateY(angle)`
- **翻转后**：底部 3 档评级按钮伴随 `AnimatedOpacity` 渐显（150ms）。

### 2.2 离场与切卡动效
用户选定评级后，不重复翻回正面，直接触发滑出离场：

- **牢记 (1)**：卡片向右滑出 `SlideTransition(dx: 1.2)` + 淡出（200ms）。
- **忘记 (3)**：卡片向左滑出 `SlideTransition(dx: -1.2)` + 淡出（200ms）。
- **模糊 (2)**：卡片轻微下坠 `SlideTransition(dy: 0.5)` + 淡出（200ms）。
- **新卡入场**：下一张新卡由中心微缩（0.95 -> 1.0）配合淡入就位（150ms）。

## 3. 桌面端快捷键

| 按键 | 动作 |
|---|---|
| `Space` | 正面/背面 3D 翻转 |
| `1` | 标记：忘记 |
| `2` | 标记：模糊 |
| `3` | 标记：牢记 |
| `← / →` | 切换上/下一张（浏览模式） |
