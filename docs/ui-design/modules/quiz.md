# 模块设计：题库答题 (Quiz)

> 路由：`/quiz` | 角色：备考核心高频刷题场景

---

## 1. 界面与布局

- **居中专注容器**：`ConstrainedBox(maxWidth: 768)`，两侧大面积留白，避免宽屏长文本阅读疲劳。
- **题目行高**：`bodyLarge`（16sp），行高固定为 `26sp`（1.625x 舒适阅读比）。
- **数学公式**：行内与块级公式无缝混排，统一由 `flutter_math_fork` 渲染。

## 2. 交互动效细节

1. **选项判定即时反馈**：
   - 点击选项立即锁死点击（`AbsorbPointer(absorbing: true)`），防重复点击。
   - **正确**：边框变绿色（`#2E9E6E`），触发 `AnimatedScale` 1.0 -> 1.02 -> 1.0（200ms）。
   - **错误**：边框变红色（`#D4453A`），触发横向抖动（180ms，振幅 4px）。
2. **解析展开**：
   - 采用 `AnimatedCrossFade` 展开解析区域，时长 250ms，避免突兀顶格跳动。
3. **桌面端快捷键**：
   - `A` / `B` / `C` / `D`：选中对应选项并判定。
   - `Enter` 或 `→`：直接进入下一题。
   - `Cmd/Ctrl + J`：呼出右侧 AI 助教解析本题。
