## 人工验收单
- [ ] 桌面端：背景照片透过面板呈磨砂质感，可辨认书堆与晨曦轮廓。
- [ ] 移动端窄屏：面板居中悬浮，透出背景且暗色遮罩未导致面板发灰。
- [ ] Tab 栏 / 输入框 / 第三方按钮均为半透明，无实色补丁感。
- [ ] 深色标题、输入文字、占位符在玻璃底上仍清晰可读。
- [ ] 错误提示条出现时保持高可读性（实色红底）。
