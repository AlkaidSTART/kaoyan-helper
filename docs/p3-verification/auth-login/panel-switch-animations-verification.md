## 人工验收单
- [ ] 点击"密码登录"：白胶囊从左平滑滑至右，两枚标签文字颜色/字重渐变过渡。
- [ ] 切回"验证码登录"：胶囊反向滑动，验证码输入框淡入并自右侧轻推就位。
- [ ] 触发校验失败：错误条自上平滑展开，下方表单被平滑推下。
- [ ] 错误消除后（如切换 Tab 自动清错）：错误条平滑收起，无残空、无突跳。
- [ ] 所有动效无卡顿，时长体感均短于 300ms。
