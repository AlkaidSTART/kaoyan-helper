## 4. 交互适配决策记录

1. **双击判定**：卡片 InkWell 同时注册 onTap/onDoubleTap，单击约 300ms 后才触发（Material 标准行为）。所有单击类测试断言前需 `pump(350ms)` 推进假时钟。
2. **长按菜单文案**：随真实数据更新（`复制院校名称与地区`、未目标态显示 `设为一志愿目标`）。
3. **旧静态字段移除**：报录比、学院·专业、音标/搭配/例句无后端来源，按 P1 ADR-4/5 移除，展示真实字段。
