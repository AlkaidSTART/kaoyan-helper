# P0 - 核心业务组件体系定义 (刷题、错题、择校、背诵)

## 1. 真实痛点与场景
- 备考考研日常包含 4 个最核心的高频场景：
  1. **刷题 (Quiz)**：沉浸答题、即时判定、官方解析与疑难一键呼叫 AI。
  2. **错题 (Mistakes)**：多维归纳检索、按连对次数科学消除、集中攻坚。
  3. **背诵 (Flashcards)**：英语单词与政治考点闪卡 3D 快速翻面，按记忆深度（忘记/模糊/牢记）分级打标。
  4. **择校 (Schools)**：根据 985/211 与专业代码多维检索报录比与历年复试线，明确竞争烈度。

## 2. 范围边界
- 实现四大模块的高保真交互视图，挂载于 `AppShell` 的 5 大核心 Tab。
- 完整落地设计规范中所要求的各微动效（选项微弹与横向微颤、3D 翻转卡片、展开折叠趋势折线、消除徽标）。
- 与现有色彩系统（暖阳、语义色、学科专属色）深度融合。

## 3. 验收指标
- 题库刷题：选项正确与错误反馈状态准确，支持解析折叠展开，支持呼出 AI 助教。
- 错题本：科目 FilterChip 使用学科专属色，错题状态正确展示与消除模拟。
- 记忆闪卡：3D 翻转流畅（<= 320ms），支持评级操作并推进进度。
- 择校报录：支持关键词与标签筛选，点击展开历年趋势与设为目标院校。
- 全工程无系统 Emoji，`flutter analyze` 零警告，所有单元及组件测试通过。
