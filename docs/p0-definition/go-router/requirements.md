# P0: GoRouter 统一路由与守卫系统需求规范

## 1. 业务痛点
1. 缺乏真实的 URL 导航能力，页面前进/后退和刷新会导致状态割裂。
2. 认证拦截依赖根组件 `AnimatedSwitcher` 的手动布尔切换，无法进行细粒度的页面级重定向拦截与重定向回跳。
3. 缺少结构化的 Tab 状态保持机制，切 Tab 容易重复加载。

## 2. 需求范围与目标
1. 全局单源路由配置，提供强类型路径常量表。
2. 未登录拦截守卫：访问除 `/login` 外任意路径自动重定向至 `/login`。
3. 登录重定向：登录成功自动跳转至 `/dashboard`。
4. 多分支状态保持：`AppShell` 下 6 个核心业务 Tab 采用 `StatefulShellRoute` 保持状态。
5. 兼容现有单测与组件调用契约，实现平滑升级。
