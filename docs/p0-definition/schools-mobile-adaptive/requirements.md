# P0: 择校模块移动端适配与触摸事件增强需求规范

## 1. 真实痛点
1. **小屏信息拥挤混乱**：`SchoolRowItem` 原先使用 `flex: 3`（院校+专业代码）和 `flex: 2`（报录比）三列水平排列，在宽度 `< 600px` 的移动端设备上，专业代码 `085404` 与报录比 `8.2:1` 挤压碰撞，视觉层级不清晰，导致数字显得突兀。
2. **缺乏移动端手势能力**：缺乏双击点赞/收藏、长按快捷动作面板等手势，仅支持单点展开，交互维度单一。
3. **触控与溢出边界问题**：
   - 展开的 3 年历年趋势数据表格在窄屏（360px ~ 400px）下 5 列数据易被截断或挤压；
   - 标签选择器横向超限可能产生溢出风险；
   - 触控热区未严格保障 `>= 48x48 dp` 标准。

## 2. 需求范围与验收指标
1. **响应式断点适配 (`< 600px`)**：
   - 窄屏下将专业代码、报录比拆为纵向层次分明的行排布，杜绝挤在中列。
   - 展开趋势表格支持横向平滑滚动（`SingleChildScrollView(scrollDirection: Axis.horizontal)`）。
   - 标签筛选区支持横向弹性触控滚动。
2. **完整触摸事件与反馈**：
   - 单击：折叠/展开趋势，触发 `HapticFeedback.lightImpact()`。
   - 双击：快速切换一志愿目标院校，触发 `HapticFeedback.selectionClick()` 与 SnackBar 提示。
   - 长按：唤起底部操作抽屉（`showModalBottomSheet`），提供快捷设为目标与复制专业代码功能，触发 `HapticFeedback.mediumImpact()`。
   - 下拉刷新：`RefreshIndicator` 支持下拉刷新并给予触控反馈。
3. **可访问性与触控热区**：
   - 关键操作按钮触控热区保证 `>= 48x48 dp`。
