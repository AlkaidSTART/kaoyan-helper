# P0 - Web 自适应布局定义

## 1. 真实痛点与场景
- 考研备考学生长时间在 Web / 桌面端使用，需要宽屏的高效利用。
- 并行任务多（如边看题边用 AI 答疑），需要三栏式布局支撑并发交互。
- 长时间盯屏，需要沉浸式、抗疲劳、留白足够的 UI。

## 2. 范围边界
- 实现基于 `LayoutBuilder` 和 `MediaQuery` 的断点检测。
- 仅实现 Shell (壳) 结构，内部模块内容区留白处理。
- 不包括具体的 AI 会话逻辑、网络请求。

## 3. 验收指标
- 桌面端 (>=1024px) 呈现 TopAppBar + 左侧 NavRail + 中间内容 (MaxWidth 960) + 右侧 AI 抽屉。
- UI 不产生系统 Emoji。
- 支持展开/折叠面板。
- 纯 Dart/Flutter 编写，无 Linter 警告。
