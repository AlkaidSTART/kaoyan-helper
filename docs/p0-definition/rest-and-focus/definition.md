# P0 - 休息放松与专注管理定义 (Rest & Focus)

## 1. 真实痛点与场景
- 考研备考学生平均每日盯屏 6-10 小时，极易产生视神经疲劳与焦虑情绪。
- 需要即时的心率平复工具（深呼吸）、趣味解压工具（考研木鱼飘字功德）以及专注度唤醒训练（舒尔特方格）。
- 用户需要全局常驻的番茄钟辅助保持 25 分钟专注 / 5 分钟休息的健康节奏。

## 2. 范围边界
- 页面：在导航栏显式挂载 `/rest` 休息页，集成深呼吸、解压木鱼、舒尔特方格三种模式。
- 全局悬浮球：在 AppShell 层实现悬浮番茄钟气泡，支持收起/展开与模式选择。

## 3. 验收指标
- 导航栏显式展示“休息” Tab，点击顺畅切入休息放松视图。
- 木鱼敲击具备物理下沉动效（`scale: 0.92`，`90ms`），且文字向上飘散浮升（如“上岸+1”）。
- 舒尔特方格支持 1-25 乱序点选与正确淡化反馈。
- 全工程无系统 Emoji，`flutter analyze` 零警告，所有单元及组件测试通过。
