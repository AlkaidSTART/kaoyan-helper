# P0 - 登录拦截与 Mock 登录定义

## 1. 真实痛点与场景
- 应用启动时需严格保障权限与用户身份，未登录状态必须自动拦截在登录页，杜绝未认证访问。
- 当前处于研发与 UI 验证阶段，真实后端（Supabase/SMS网关）尚未联调，开发者与测试人员需要开箱即用的 Mock 登录闭环，快速验证看板与各功能模块。

## 2. 范围边界
- 默认拦截：首次启动或未授权时始终挂载 `LoginPage`。
- Mock 登录：支持通过测试手机号（如 `13800000000`）配合验证码（`123456`）或点击“测试账号一键填入”直接完成认证。
- 登出闭环：支持从主界面安全登出并重新拦截回登录页。

## 3. 验收指标
- 启动应用默认停留在登录界面。
- 点击“测试账号”后自动填入有效凭证并勾选协议。
- 登录后进入 `AppShell`，顶部显示 Mock 用户数据（浙江大学 · 计算机专硕）。
- 点击右上角头像选择“退出登录”，平滑切回登录页。
- 通过静态检查 `flutter analyze` 与全部自动化测试。
