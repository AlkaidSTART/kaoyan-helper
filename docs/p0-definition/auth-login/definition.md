# P0 - 励志登录与用户认证定义

## 1. 真实痛点与场景
- 考研学习过程漫长且单调，启动应用时的第一印象极其重要。登录页需要兼顾心理动能激发与高效极速认证。
- 宽屏 Web/桌面端使用全屏背景自习室图片时，容易因卡片遮挡重点文案（如“考研 让你遇见更好的自己”）而破坏沉浸感。

## 2. 范围边界
- 界面实现：基于 `assets/logo.png` 实现桌面端右侧避让悬浮毛玻璃认证卡片，移动端纵向分层。
- 功能实现：手机号/邮箱输入、验证码与密码模式切换、协议勾选校验、登录中状态反馈。
- 架构集成：封装 `AuthRepository` 与 `AuthNotifier`，UI 不直连外部 API。

## 3. 验收指标
- 完整展示桌面右侧悬浮毛玻璃卡片（`BackdropFilter` sigma 16，圆角 24，光晕边框）。
- 晨曦金双色渐变登录按钮带按压缩放反馈（`scale: 0.98`，`90ms`）。
- 全程无 Emoji，图标使用 Material Symbols Outlined。
- `flutter analyze` 零警告，相关测试全覆盖通过。
