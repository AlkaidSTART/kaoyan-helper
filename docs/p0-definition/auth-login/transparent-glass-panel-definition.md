# P0 - 登录面板通透玻璃质感 · 定义

## 问题
`AuthGlassCard` 虽挂了 `BackdropFilter`，但面板填充为 `0xCCFFFDF9`（80% 不透明暖白），背景自习室摄影图几乎被完全遮死，"毛玻璃"效果名不副实，观感笨重。

## 目标
登录注册面板呈现真正的通透玻璃 (Glassmorphism) 质感：
1. 面板填充不透明度降至 20%~45%，背景照片透过模糊层清晰可见。
2. 模糊层轻微提升背景饱和度，营造高级玻璃折色感。
3. 面板内部二级容器（Tab 栏、输入框、第三方按钮、分隔线）同步半透明化，避免出现"实色补丁"。

## 范围边界
- 仅调整视觉样式（填充、边框、模糊参数、分隔线颜色），不改布局结构、不改任何业务逻辑与交互行为。
- 错误提示条保持高不透明度，确保警示信息可读性。

## 验收指标
1. `flutter analyze` 零问题，`flutter test` 全部通过。
2. 桌面端/移动端登录页背景照片透过面板可见且呈磨砂质感。
3. 面板内深色文字与占位符仍可读，无明显对比度劣化。
