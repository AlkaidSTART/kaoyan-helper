# P0 - 登录面板切换动效 · 定义

## 问题
`AuthGlassCard` 内三处状态切换均为瞬间硬切，无任何过渡：
1. Tab 胶囊（验证码登录/密码登录）选中态白底瞬间跳位。
2. Tab 切换时验证码输入框与密码输入框瞬间替换。
3. 错误提示条出现/消失瞬间弹出，且会突兀地顶开下方表单。

## 目标
三处切换均获得自然、克制的过渡动效，与玻璃面板的轻盈质感匹配。

## 范围边界
- 仅加动效，不改布局结构、不改业务逻辑与交互触发条件。
- 遵守守则：单动效时长 ≤ 400ms，物理自然曲线（easeOutCubic / easeInCubic）。

## 验收指标
1. `flutter analyze` 零问题，`flutter test` 全部通过。
2. Tab 胶囊平滑滑动，文字颜色渐变过渡。
3. 表单切换为淡入 + 轻微滑动，无布局跳动。
4. 错误条展开/收起平滑，下方表单被平滑推压而非瞬跳。
