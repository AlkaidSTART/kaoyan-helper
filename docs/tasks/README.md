# 任务回溯记录 (Task & Session Logs)

> 目录目标：记录每次对话/迭代的具体任务规划、实施方案以及变动的文件清单，确保每一次研发动作均可精准回溯与审计。

---

## 任务记录目录规范

每次启动一个非琐碎任务（或一次功能讨论与规划对话）时，在当前目录下新建以日期和任务主题命名的子文件夹：
`docs/tasks/YYYY-MM-DD-<task-name>/`

每个任务子目录下必须包含以下文件：
1. **`plan.md`**：记录本次对话/任务的原始需求、技术决策、实施计划与方案设计。
2. **`changed-files.md`**：完整记录本次任务新增、修改、重构或删除的所有文件路径及改动原因。
3. **`summary.md`**（可选或整合在 plan 中）：交付总结、遗留问题与下一步建议。
