# Task Plan: 择校模块移动端适配与触摸事件增强

## 原始诉求
优化移动端择校页面布局，解决窄屏下专业代码与中间列报录比挤压突兀的问题，同时全面补充移动端触摸事件与触控交互体验。

## 架构与设计决策
1. **多断点分层渲染**：使用 `LayoutBuilder` 识别 `maxWidth < 600`，小屏下将院校名称、专业代码与报录比纵向拆分，专业代码不再侵入报录比中列。
2. **手势操作闭环**：
   - 单击：平滑展开/折叠历年 3 年报录数据。
   - 双击：快速切换一志愿目标收藏，带有触觉震动反馈。
   - 长按：唤起底部操作菜单（`showModalBottomSheet`），支持快捷设为目标与复制专业代码。
3. **表格与标签弹性横滑**：
   - 标签选择器支持横向触控滑动；
   - 历年报录数据表格包裹横向滚动视图，彻底消除小屏溢出隐患。
4. **全套自动化测试覆盖**：在移动端分辨率（`390x844`）下覆盖布局渲染、手势触发与动作反馈。
